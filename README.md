# Beyond the Orange Wire

**Designing, Loading and Troubleshooting High-Leg and Open-Delta Services**

An open application note on 120/240 V four-wire delta services: the closed
(high-leg) delta and the open delta. It covers the theory, the NEC 2023
requirements, the "208 V question", common field problems, and two worked
examples designed from scratch:

- **Commercial:** a casual-dining restaurant with an all-electric cooking line
  on a closed high-leg delta service.
- **Industrial:** a 250 m³/day seawater reverse-osmosis (SWRO) plant on a
  utility open-delta service.

> **Status:** v0.1 in progress. The outline is complete and Section 3.2
> (voltage phasors of the centre-tapped delta) is drafted with its figures.
> Every code citation is tracked in the verification log and is marked
> unverified until checked against the NEC 2023 text.

## Read it

The manuscript is drafted in LaTeX on Overleaf. A snapshot of the source is
committed to `manuscript-tex/` at each milestone, and a PDF will be attached to
each tagged release.

## Check the numbers and rebuild the figures

Python 3.12, pinned with [uv](https://docs.astral.sh/uv/). From the repository
root:

```
uv sync
uv run pytest
```

To regenerate the figures, open `notebooks/hl_figures.py` in VS Code and run
its cells with the `.venv` kernel, or run it as a script:

```
uv run python notebooks/hl_figures.py
```

Outputs are written to `figures/`. Add packages with `uv add`, never
`pip install`, so `uv.lock` stays the single record of the environment.
